المضيف المحلي Ubuntu 24.04 ARM64. Android SDK Command-line Tools مثبتة (`sdkmanager` `22.0`) وكذلك `platforms;android-36` revision 2 و`build-tools;36.1.0` و`platform-tools` `37.0.3`. قُبل `android-sdk-license` وحده. `adb` و`aapt` و`aapt2` x86-64، فلم تُشغّل على ARM64. لم يُثبت Flutter أو Dart محليًا ولم تُجرَ عمليات Flutter محليًا.

## scaffold والإعدادات المولدة

أنشأ [run 44743248440](https://github.com/zikoBoss/TeleManager/actions/runs/44743248440) scaffold Android-only على `x86_64` بعد نجاح فحص الأدوات. الملفات الجديدة تشمل `pubspec.yaml` و`pubspec.lock` و`analysis_options.yaml` و`.metadata` و`lib/main.dart` و`test/widget_test.dart` وملفات Android/Gradle و`MainActivity.kt` بلغة Kotlin. الكود هو شاشة counter الافتراضية واختبارها فقط؛ لا يثبت إنجاز أي ميزة TeleManager.

إعدادات البناء التي ولّدها القالب وأثبتها السجل: Android Gradle Plugin `9.3.1`، Kotlin Gradle Plugin `2.4.20`، Gradle wrapper `9.5.0`، هدف bytecode Java/Kotlin `17`. أبلغ Gradle عن Kotlin مضمّن `2.3.20`، وهو غير إصدار plugin. `applicationId` و`namespace` هما `com.example.telemanager`، وهي قيمة placeholder من القالب وليست معرّف النشر الذي اختاره المستخدم. لم تُضف Drift أو Riverpod أو GoRouter أو TDLib.

أزال scaffold سطر تثبيت إصدار NDK من إعداد Gradle لإبقاء قرار NDK/ABI مؤجلًا. مع ذلك، سجل كل من run `44743248440` وrun المشروع `44744990391` تنزيل Gradle تلقائيًا NDK Side by side `28.2` (`r28c`) أثناء بناء APK. لم يظهر قبول ترخيص آخر؛ سجل خطوة قبول الترخيص يظل `android-sdk-license` وحده. هذا اعتماد عابر للبناء، وليس NDK pin معتمدًا للمشروع، ويجب إعادة تقييمه قبل أي شيفرة Android native.
