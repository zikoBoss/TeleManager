# الأمن والخصوصية

هذه مبادئ تصميم إلزامية من المخطط؛ لا تدعي وجود تنفيذ أمني بعد.

- لا تسجل Telegram API credentials أو رموز الدخول أو كلمات المرور أو بيانات الجلسة أو مفاتيح التشفير.
- خزّن بيانات TDLib داخل مساحة التطبيق الخاصة؛ قيّم Android Keystore للأسرار المحلية عند الملاءمة.
- شفّر النسخ الاحتياطية بـ AES-GCM عبر مكتبة موثوقة، مع إصدار مخطط وسلامة SHA-256؛ لا تضع المفاتيح الخام في النسخة.
- صمّم استعادة لا تعتمد على الهاتف القديم فقط، واشرح حفظ/استعادة المفتاح أو عبارة الاسترداد وفقدانه.
- وضّح أن Telegram Cloud Chats لا توفر تشفير Secret Chats طرفًا لطرف.
- لا ترفع أي ملف دون إجراء صريح من المستخدم.
- تنظيف Cache محلي لا يحذف أصل Cloud. الحذف السحابي دائم/نهائي يتطلب تأكيدًا واضحًا منفصلًا؛ دعم Trash/Soft Delete قابل للدراسة.
- لا تنفذ APK أو Scripts أو مستندات غير موثوقة تلقائيًا.
- تحقق من سلامة الأجزاء والملف بعد إعادة التجميع قبل النجاح.
- التزم بشروط Telegram API، ولا تعتمد على روابط تنزيل مباشرة دائمة.
- لا تعتبر الملف آمنًا لمجرد امتداده؛ استخدم MIME/signature عند الحاجة.
